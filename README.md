# SLIM — A grande escolha

Site estático com tema vermelho, foto do grupo, animações e explosão de estrelas.

## Arquivos

- `index.html`: página principal.
- `style.css`: tema e layout responsivo.
- `app.js`: animações, interação e som opcional.
- `foto.png`: foto do grupo.
- `.nojekyll`: publicação dos arquivos estáticos sem Jekyll.

## Hospedagem

Extraia o ZIP e coloque estes arquivos na raiz do repositório que será publicado no GitHub Pages. Preserve os nomes e mantenha os arquivos juntos.

Não precisa instalar dependências, compilar nem configurar servidor. Os caminhos são relativos e funcionam também em páginas de projeto.

A fonte Space Grotesk é carregada pelo Google Fonts. Se não carregar, o site usa Arial. O som começa desativado.

A opção de movimento reduzido do dispositivo diminui as animações.
